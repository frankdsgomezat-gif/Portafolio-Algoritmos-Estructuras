Este repositorio contiene el portafolio académico del curso. La página principal está preparada para GitHub Pages.

## Estructura
- `index.html` — página principal.
- `css/` — estilos.
- `img/` — logo y foto.
- `unidades/` — unidades y semanas.
- `proyectos/` — proyectos de Apache NetBeans.
- `documentos/` — documentos generales.

## Para agregar una nueva semana
Crea una carpeta como:
`unidades/unidad-1/semana-17/`

Dentro puedes colocar:
- `index.html`
- PDFs
- imágenes
- código fuente
- archivos de proyectos

Luego agrega el enlace de la nueva semana en `index.html`.

## GitHub Pages
En GitHub entra a **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. GitHub Pages publica archivos estáticos del repositorio.
